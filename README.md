# Signature-Based Antivirus System

A web-based antivirus application developed using Python and Flask that detects malicious files using signature-based detection techniques.

## Features
- Quick Scan
- Custom File Scan
- Malware Detection
- Quarantine Management
- Scan History Tracking
- Dashboard Analytics
- Web-Based User Interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- CSV Dataset
- Cybersecurity Concepts

## Project Workflow
1. User uploads or scans files.
2. System analyzes file signatures.
3. Signatures are matched against known malware patterns.
4. Malicious files are quarantined.
5. Scan results are displayed on the dashboard.

## Future Improvements
- Real-time protection
- Machine Learning based detection
- Automatic malware signature updates
